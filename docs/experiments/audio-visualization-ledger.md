# Audio visualization experiment ledger

## Context

- Topic: independent, composable terminal views for WAV artifact diagnosis.
- Owner scope: `tools/audio_analysis.py`, its private modules/tests, and `docs/audio-analysis.md` captures.
- Correctness gate: audio/PSG tests, CLI help, JSON/quiet stream separation, deterministic screenshot regeneration.
- Evidence gate: a focused synthetic fixture must make the proposed artifact visibly localizable beside an existing explanatory view.
- Dirty-tree constraint: preserve unrelated PSG, RTL, build, and OpenSpec work; do not stage it.
